## How to Use This Index

1. **Find your question** — Use the table above
2. **Open the source file** — Click the link or open the corresponding `.md` file
3. **Scroll to the solution** — Solutions are at the bottom of each practice file
4. **Compare approaches** — Don't just copy; understand *why* the solution works

## Search Tips

- In VS Code: `Ctrl+P` → type `Phase1Q.md` → `Ctrl+Shift+O` → type question number
- In browser/GitHub: Use the anchor links (e.g., `#solution-15`)
- In terminal: `grep -n "Solution 15" Phase1Q.md`
