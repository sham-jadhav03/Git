## 🎯 Learning Philosophy

| Principle | Description |
|-----------|-------------|
| **Don't rush** | Each phase has a reason for its position. Skipping ahead means confusion later. |
| **Code along** | Watching is not learning. Type every example yourself. |
| **Revisit** | After Phase 3, go back to Phase 1 examples. After Phase 5, revisit Phase 2. |
| **Build projects** | They tie concepts together. |
| **Ask questions** | If something doesn't click, it's almost always a missing piece from an earlier phase. |

## 🚀 Getting Started

### Prerequisites
- **VS Code** (recommended) — [code.visualstudio.com](https://code.visualstudio.com)
- **Node.js** — [nodejs.org](https://nodejs.org) (includes npm)
- Browser DevTools (F12 in Chrome/Firefox/Edge)

### How to Run Code

**Browser Console** (fastest for snippets):
1. Open any page → F12 → Console tab
2. Type JavaScript directly

**VS Code + Node.js** (for files):
```bash
# Create a file
code app.js

# Run it
node app.js
```

## 📖 How to Use These Files

### For Learning
1. **Read the phase lesson** (`Phase1Foundation.md`) — understand concepts
2. **Attempt practice questions** (`Phase1Q.md`) — solve without looking at solutions
3. **Check solutions** — compare your approach, understand differences
4. **Build the mini projects** — they're the integration test

### For Teaching
- Each phase lesson is structured as a complete class
- Practice sheets have difficulty markers: `Foundation` • `Intermediate` • `Challenge`
- Solutions include explanations, not just code
- Interview/conceptual questions at the end of each practice sheet

## 🧪 Phase 1 — Quick Reference

### Topics Covered
- What is JavaScript? Engines, where it runs
- Environment setup (browser, VS Code, Node.js)
- `console.log`, comments
- Variables: `var`, `let`, `const`, naming conventions
- 7 primitive types + `object`
- `typeof`, type conversion vs coercion
- Operators: arithmetic, assignment, comparison, logical, ternary
- Strings (template literals, methods)
- Numbers (`Math`, `parseInt`, `parseFloat`)
- Conditionals: `if/else if/else`, `switch`
- Loops: `for`, `while`, `do...while`, `for...of`
- `break` / `continue`
- User input: `prompt()`

### Mini Projects
1. **Simple Calculator** — basic arithmetic with input validation
2. **FizzBuzz** — classic interview problem
3. **Number Guessing Game** — random + loops + conditionals
4. **Temperature Converter** — C↔F with formatting
5. **Count Vowels** — string iteration + methods
